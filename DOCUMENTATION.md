# Документация TODO Navigator

Расширение для Visual Studio Code на TypeScript. Находит `TODO:` и `FIXME:` в текущем файле и переносит курсор к выбранной заметке.

**Автор:** Шибанов Никита Дмитриевич, группа M3120.  
**Версия:** 1.0.1. **IDE:** Visual Studio Code 1.85 или новее.

## Использование

Добавьте заметку на отдельной строке или после кода:

```text
// TODO: добавить проверку
return 1; // FIXME: обработать ошибку
# TODO: задача в Python
/* TODO: задача в блочном комментарии */
```

Нажмите `F1`, введите `TODO Navigator` и выберите команду:

- **Показать все заметки** — общий список TODO и FIXME.
- **Только TODO** — список задач.
- **Только FIXME** — список замечаний об ошибках.

Введите часть описания или номер строки для поиска. `Enter` выполняет переход, `Escape` закрывает список. Общий список также доступен через правую кнопку мыши в редакторе.

Двоеточие после метки обязательно, регистр не важен. Поддерживаются префиксы `//`, `#`, `/*`, `*` и метки без префикса в начале строки. На одной строке находится одна заметка. Учитываются несохранённые изменения. Если документ изменился во время выбора, команду нужно запустить повторно.

Поиск построчный, без полного синтаксического анализа языка. При поиске комментария после кода пропускаются обычные строковые литералы; специальные и многострочные литералы могут распознаваться неточно.

## Сборка и запуск из исходников

Для сборки нужны Node.js 22 или новее и npm. Выполните в папке проекта:

```bash
npm ci
npm run compile
code --new-window --extensionDevelopmentPath="$PWD"
```

В отдельном окне VS Code откройте текстовый файл и выполните команду плагина. Скомпилированные файлы появятся в `out`, зависимости — в `node_modules`.

Для установки готового `.vsix` исходники не нужны: `F1` → **Extensions: Install from VSIX…** → выбрать установочный файл. После обновления выполните **Developer: Reload Window**.

## Устройство

- `src/parser.ts` — поиск заметок, фильтрация по типу и подсчёт; результаты хранятся в массиве объектов.
- `src/extension.ts` — регистрация команд, список заметок и переход к выбранной строке через API VS Code.
- `package.json` — манифест расширения и зависимости сборки.
- `tsconfig.json` — настройки TypeScript.
- `package-lock.json` — зафиксированные версии зависимостей.

## Порядок работы

VS Code читает манифест `package.json` и при первом запуске команды вызывает `activate`. Расширение получает текст активного документа, собирает заметки в массив, фильтрует их и показывает стандартный список Quick Pick. После выбора проверяется версия документа и выполняется переход к метке.

```text
Команда → чтение документа → поиск → фильтрация → список → переход
```

Если файл не открыт или заметок нет, выводится сообщение. Пустое описание отображается как «(без описания)». Расширение не изменяет текст файла.

## Функции

| Функция | Назначение | Пример вызова |
| --- | --- | --- |
| `parseTodos(text)` | Находит заметки и возвращает массив объектов с типом, текстом, строкой и столбцом | `parseTodos('// TODO: проверить ввод')` |
| `findCommentStart(line)` | Ищет начало комментария вне обычных строковых литералов; возвращает его индекс либо -1 | `findCommentStart('return 1; // TODO: проверка')` |
| `filterTodos(items, kind?)` | Возвращает заметки нужного типа или копию всего массива, сохраняя порядок | `filterTodos(notes, 'TODO')` |
| `summarizeTodos(items)` | Считает количество TODO и FIXME | `summarizeTodos(notes)` |
| `activate(context)` | Регистрирует три команды расширения; вызывается средой VS Code | `activate(context)` |
| `showNotes(kind?)` | Читает документ, показывает список и выполняет переход к выбранной заметке | `showNotes('FIXME')` |

`findCommentStart` и `showNotes` — внутренние функции. Строка и столбец в объекте заметки отсчитываются от нуля; пользователю показывается номер строки, увеличенный на единицу. К функциям в исходниках добавлены JSDoc-комментарии.

Пример результата анализа:

```typescript
const notes = parseTodos('// TODO: проверить ввод');
// [{ kind: 'TODO', text: 'проверить ввод', line: 0, column: 3 }]

summarizeTodos(notes);
// { TODO: 1, FIXME: 0 }
```
