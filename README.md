# TODO Navigator

Расширение для Visual Studio Code на TypeScript. Находит `TODO:` и `FIXME:` в текущем файле и переносит курсор к выбранной заметке.

**Автор:** Шибанов Никита Дмитриевич, группа M3120.  
**Версия:** 1.0.1. **IDE:** Visual Studio Code 1.85 или новее.

## Возможности

- Поиск TODO и FIXME в текущем файле, включая комментарии после кода и несохранённые изменения.
- Общий список, фильтры по типу и счётчики заметок.
- Поиск по описанию или номеру строки и переход к выбранной метке.
- Отмена выбора, сообщения при отсутствии файла или заметок и проверка изменений документа перед переходом.

## Использование

Добавьте строку `// TODO: добавить проверку`. Нажмите `F1`, введите `TODO Navigator` и выберите **Показать все заметки**, **Только TODO** или **Только FIXME**. `Enter` выполняет переход, `Escape` закрывает список. Общий список также доступен в контекстном меню редактора.

Для установки готового `.vsix`: `F1` → **Extensions: Install from VSIX…** → выбрать файл. После обновления выполните **Developer: Reload Window**.

## Сборка

Нужны Node.js 22 или новее и npm. Выполните в папке проекта:

```bash
npm ci
npm run compile
code --new-window --extensionDevelopmentPath="$PWD"
```
